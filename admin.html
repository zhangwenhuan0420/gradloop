管理者控制台

这是 GradLoop 免费市场调研版的管理入口。当前版本部署在 GitHub Pages， 适合展示、拉新和验证需求；真正的删帖、审核、举报处理和用户管理，需要下一阶段接入数据库和后台权限。

Current version

你现在能管理什么

平台规则和页面内容

你可以通过 GitHub 仓库更新首页文案、交易规则、安全提示、城市和品类。

市场调研入口

你可以把公开链接发给同学，收集他们是否愿意发布二手商品、想要哪些功能。

人工运营策略

试用期可以用微信群、表单或私信收集举报和反馈，先验证用户愿不愿意用。

当前版本不能做的事

  • 你看不到所有用户发布的商品，因为商品只存在发布者自己的浏览器里。
  • 你不能远程删除别人的商品，也不能真正封禁用户。
  • 你不能处理真实保证金、退款、站内聊天或支付纠纷。
  • 刷新、换设备、清理浏览器数据后，本地演示数据可能消失。

真正平台后台需要这些模块

用户和学生认证

注册登录、.ac.uk 邮箱验证、手机号验证、黑名单和用户评分。

商品数据库

所有发布内容进入数据库，管理员可搜索、下架、恢复、标记可疑商品。

举报和客服工单

买卖双方提交证据，客服按规则处理投诉、记录结果和扣罚建议。

聊天和交易状态

站内私信、交易流程、已约面交、已完成、投诉中、已关闭。

数据看板

查看每日发布数、热门城市、热门品类、转化率、举报数量和留存。

合规支付接入

等验证出真实需求后，再考虑 Stripe Connect、Adyen、微信支付或支付宝商户接入。
